# NYC Airport Radar 🚕

Rideshare haydovchilar uchun jonli aeroport xaritasi: JFK, LaGuardia (LGA) va Newark (EWR).

## Imkoniyatlar
- 📍 Jonli GPS kuzatuv va tezlik (mph) ko'rsatkichi — 65 mph dan oshsa ogohlantirish
- ✈️ Har bir aeroportgacha real marshrut (OSRM), masofa va yetib borish vaqti
- 🎯 Aeroport atrofida 3 millik zona doirasi
- 🔥 Soatga qarab talab holati: HIGH DEMAND / NIGHT FLIGHTS / STEADY FLOW
- 🧭 Marker yoki pastdagi doirani bosish — darhol navigatsiya ochiladi
